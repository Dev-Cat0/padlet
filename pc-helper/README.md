# Padlet PC 브라우저 도우미

1. Windows에 Python 3.12 이상을 설치합니다. 설치 시 Add Python to PATH를 선택하세요.
2. ZIP을 모두 압축 해제하고 `start.cmd`를 실행합니다. 첫 실행은 의존성과 Chromium을 설치하므로 잠시 걸립니다.
3. https://dev-cat0.github.io/padlet/?v=pc-1 에서 PC 연결 코드를 발급하고 도우미에 입력합니다.
4. 패널에 대상 게시판을 입력하고 **내 PC 브라우저 열기**를 누릅니다.
5. PC에 열린 Chromium에서 직접 로그인하고 글을 한 번 게시합니다.
6. 성공한 게시 요청이 캡처되면 브라우저가 닫힙니다. 웹 패널에서 제목·본문·횟수를 설정하고 전송하세요.

연결 코드는 5분 동안 유효하고 1회만 쓸 수 있습니다. Render 재배포 또는 세션 만료 후에는 다시 연결하세요.

일반 브라우저 프로필과 분리된 임시 Chromium을 사용합니다. 로그인 비밀번호를 서버로 보내지 않습니다. 성공한 Padlet 게시 요청의 쿠키·인증 헤더와 본문을 **고정된 본인 Render 서버 https://padlet-sender-panel.onrender.com**에 HTTPS로 전달해 원본 Python과 같은 후속 전송을 수행합니다. 캡처 정보는 서버 메모리에만 보관되며 패널의 「로그인·캡처 정보 삭제」로 삭제할 수 있습니다.

캡처 후 전송은 Render에서 실행되므로 PC 도우미를 닫아도 계속됩니다. PC 브라우저가 실행 중일 때 도우미를 닫으면 해당 브라우저도 종료됩니다.
