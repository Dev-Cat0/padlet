# Padlet 익명 전송

가상 브라우저 없이 사용자의 **실제 Padlet 탭**에서 실행하는 익명 전용 도구입니다. 웹 페이지는 즐겨찾기 실행 버튼만 제공합니다. 전송 내용·쿠키·세션을 Render나 다른 전송 서버로 보내지 않습니다.

웹 페이지: https://dev-cat0.github.io/padlet/

## 사용 방법

1. 웹 페이지의 **익명 Padlet 전송** 버튼을 즐겨찾기 바에 드래그합니다. 별도 확장 프로그램이나 Python 설치는 필요하지 않습니다.
2. 시크릿 창에서 대상 Padlet을 엽니다. **Padlet 계정에 로그인하지 않습니다.**
3. 저장한 즐겨찾기를 실행합니다. 익명 상태가 확인되면 Padlet 화면에서 글을 1건 직접 게시합니다. 패널을 접으면 원래 게시판을 조작할 수 있습니다.
4. 성공한 요청이 캡처되면 제목·본문·섹션당 횟수·주기를 설정하고 전송합니다. 첨부·추가 입력 항목은 처음 성공한 게시물의 값을 유지합니다.
5. 중지는 진행 중인 요청의 결과를 받은 뒤 멈춥니다. 종료는 패널과 요청 관찰기를 제거합니다. 탭을 닫거나 다른 게시판으로 이동하면 계속 전송할 수 없습니다.

처음 수동 게시한 1건은 실제 게시물로 남으며 반복 횟수에 포함되지 않습니다. 기본값은 섹션당 50회 / 주기 0.3초, 0회는 무제한입니다. 모든 섹션에 각 1건씩 전송하며, 섹션이 없으면 게시판에 1건입니다. 익명 확인과 응답 시간이 추가되므로 실제 간격은 설정값보다 길어질 수 있습니다. 백그라운드 탭은 브라우저의 타이머 제한으로 느려질 수 있습니다.

## 익명 확인과 오류 처리

- 실행 시, 성공 요청 캡처 시, **각 자동 POST 직전**에 게시판 초기 상태를 읽습니다.
- 익명 방문자의 ID·hashid와 `registered_at: null`을 확인합니다. 계정 등록 정보·username·email이 있거나 익명 여부를 확인할 수 없으면 차단합니다.
- 캡처한 작성자 ID와 현재 익명 사용자가 일치해야 합니다. 실행 중 로그인·사용자 변경·게시판 변경을 감지하면 자동 전송을 중지합니다.
- 익명은 Padlet 계정에 로그인하지 않은 상태입니다. IP 주소를 숨기는 기능은 아닙니다. 시크릿 창에서도 로그인하면 전송을 차단합니다.
- 성공한 POST `/api/9/wishes`의 형식을 유지하고 새 cid·시각·섹션을 설정합니다. 수정하지 않은 HTML 본문과 추가 필드는 유지하며 수정한 본문만 이스케이프합니다.
- HTTP 401·403·보안 확인·성공을 확인할 수 없는 응답·네트워크 오류는 중지합니다. 마지막 요청의 성공 여부가 불분명할 때 자동 재전송하지 않습니다.
- 429는 최소 3초와 더 긴 숫자형 Retry-After를 기다리고 해당 주기에서 미완료된 섹션만 재시도합니다. 성공한 섹션을 중복 전송하지 않습니다.
- 브라우저의 정상 쿠키·CSRF를 같은 출처 안에서 사용합니다. 쿠키를 읽어 내보내거나 별도 HTTP 클라이언트로 이전하지 않습니다. POST는 리디렉션을 따라가지 않습니다.
- 사이트 보안 설정이나 모바일 브라우저에 따라 즐겨찾기 실행이 제한될 수 있습니다. 보안 확인은 사용자가 Padlet에서 직접 처리하며 자동 해결하지 않습니다.

## 구성

- `web/index.html`, `web/app.js`, `web/style.css`: 설치 없는 즐겨찾기 실행 안내. 같은 출처의 실행 코드만 읽습니다.
- `web/anonymous.js`: Padlet 탭에 작은 패널을 표시하고 익명 확인, fetch/XHR 성공 요청 관찰, 같은 브라우저에서 전송을 처리합니다. 로컬 저장소나 전송 서버를 사용하지 않습니다.
- `server/`: 이전 버전과 호환하기 위한 서버 코드. 현재 웹 화면에서는 호출하지 않습니다. 이전 브라우저 캡처 경로도 로그인된 작성자를 거부합니다.
- `desktop/`, `pc-helper/`: 이전 구현 보존용. 현재 사용자 흐름에 필요하지 않습니다.

GitHub Pages는 `main`의 `web/` 변경 시 `.github/workflows/pages.yml`로 배포합니다. 현재 사용자 흐름에는 Render 서버를 켜거나 가상 브라우저를 실행할 필요가 없습니다.

## 검증

```powershell
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python -m playwright install chromium
.\.venv\Scripts\python tests/ui_smoke.py
.\.venv\Scripts\python tests/anonymous_ui_smoke.py
node --check web/anonymous.js
```

익명 전송 통합 테스트는 엄격한 CSP를 적용한 모의 게시판에서 실제 Chromium의 즐겨찾기 탐색으로 실행합니다. fetch/XHR 캡처, 익명 전송, 로그인·신원 불명·작성자 변경 차단, 보안 확인 중지, 성공 응답 검증, 429 중복 방지를 검사합니다. 모든 네트워크 요청은 로컬 모의 응답이며 실제 게시판에 글을 올리지 않습니다.
